# Frontend map (frontend/)

> Split out of `CLAUDE.md` (2026-08-17) to keep the always-loaded file small. Content is verbatim; `CLAUDE.md` carries a one-line index entry pointing here.

**Pages** (App Router; routes map 1:1 to a component in `app/components/` unless noted). Non-obvious notes only:
- `/backtest` (renamed from `/momentum` 2026-05-19) — variant-sweep backtester + saved runs. (The in-page "Current Picks" / saved-snapshot UI was removed 2026-06-03; current-picks is now produced only by the scheduled pipeline + cron, surfaced on `/schedule` and the admin API — the backend `mode=current_portfolio` path is untouched.) Universe dropdown lists **only frozen static snapshots** (`/api/static-universes` — `frozen_at` set; the live pipeline-managed templates ACWI/Leonteq/ACWI∩Leonteq are intentionally NOT pickable so a saved run stays reproducible — freeze a copy to backtest one; the monthly LongEquity is excluded by being non-static). The loader broadcasts each snapshot's single month across history (`broadcast_constant`). Backend backstop: `monthly_universe_labels()` rejects any monthly universe. URL is general so more strategies can land without a rename.
- `/acwi` — top: canonical ACWI universe (template-managed) with date scrubber + searchable membership + "Refresh now"; bottom: live iShares holdings + MSCI announcement + net-additions explorers (reconstruction diagnostics). No manual "Save universe" — the pipeline refreshes it.
- `/fees` — per-exchange one-way fees + broker-support toggle (sticky Save, no auto-save). Unsupported exchanges are dropped from the backtest universe entirely (filter in `backtest_stream/stream.py` right after `load_universe`). Backtest stats render `gross (net)` via a trade-aware fee model (buy fee on first appearance, sell fee when not rolled forward, open period never pays sell); net computed client-side in `momentum/feeStats.ts` so fee edits update parentheticals without re-running.
- `/schedule` — scheduled pipeline UI. Top: scheduled-strategies list (expand → per-strategy run history → holdings via `MonthlyHoldingsTable`). Middle: weekly/monthly job cards + "Run now". Bottom: recent runs (five-dot phase pip, expand → per-template diff + searchable membership + per-strategy holdings).
- `/api` — admin-only interactive endpoint explorer (uses the live Supabase session as Bearer). `/documentation` — admin-only external-script reference (full `bbterminal_client.py`, curl/PowerShell quick-start, endpoint table).
- `/login`, `/set-password` — auth; redirect to `/` on success. `frontend/proxy.ts` enforces auth on non-public routes and bounces authed users off `/login`.
- **Frozen-only policy (2026-06-15)**: universes are listed frozen-snapshots-only EVERYWHERE selectable/browsable — `/backtest` (useStaticUniverses; `/regime-detector` shared this and was **deleted 2026-08-03**), `/earnings` (`/api/earnings/universes`), `/universe` screener (`/api/universe/labels` filtered `frozen_at IS NOT NULL`), `/companies` memberships. The ONLY exception is `/longequity-universe`'s own per-month view. The management pages (`/acwi`, `/sp500`, `/leonteq`) still show their LIVE universe as the freeze *source* (you freeze a copy from there). **Leonteq freeze applies a market-cap floor** — settable from the `/leonteq` "Min cap €B" input (defaults to `LEONTEQ_MIN_MARKET_CAP_EUR` = €1B; passed as the `min_market_cap_eur` query param to the freeze endpoint, 0 disables): only companies with a known `market_cap_eur` ≥ floor are frozen in; below-floor or no-cap are dropped. A company with no cap that's **GuruFocus-UNSUBSCRIBED is dropped silently**, but a **subscribed** company with no cap is returned in the freeze result's `missing_market_cap` list (and shown on `/leonteq`) — a data gap to fix via "Refresh market caps" before re-freezing. All other freezes (ACWI/SP500/LongEquity) have no cap floor.


- `/signal-lab` — `?include_daily=true` (default **false**, off because it roughly doubles compute: 31s → 110s on the 4,006-name universe) additionally scores the `daily_asof` signals `/schedule` actually trades, keyed `daily.<name>` with a `cadence` field on every row. Do not render a signal without its cadence: `vol_trend_3m` and `daily.vol_trend_3m` are different measures with near-identical labels.

Others (orientation): `/` welcome · `/longequity-universe` · `/airs-portfolio` · `/companies` · `/benchmarks` · `/earnings` · `/universe` (criteria screener) · `/sp500` (import + inspect current S&P 500, freeze-a-copy) · `/fx-rates` · `/request_gurufocus`.

- **`/earnings` (`EarningsDashboard.tsx`)** has ONE Stock/Portfolio switch (`aMode`; side B follows via `const bMode = aMode`):
  - **Stock mode**: the earnings dashboard (charts + Snapshot Stats) for a company, optionally compared against **another company** (no portfolio-on-a-side).
  - **Portfolio mode**: shows ONLY the **Allocation × Selection matrix** (`AttributionMatrix`) comparing two **baskets** — saved portfolios and/or frozen-universe snapshots → `GET /api/earnings/management-dashboard/attribution?a=&b=&a_kind=&b_kind=&universe=&year=` (`_basket_members` dispatches portfolio vs universe; chunk all `.in_()` over the union — two large universes overflow a single URI). No charts/snapshot; the matrix has its own price-only load.
  - Basket charting + per-member breakdown tooltips were retired with this simplification (the `aggregateBasketMetrics`/`MemberRanking`/basket `member-metrics` machinery + the `start_year` floor on the basket loaders are now dormant). The basket-metrics endpoints still exist (admin/API surface) but the dashboard no longer charts baskets.

**Language (2026-08-18)** — the app is English; **one surface is translatable**: the Fundamental modal's **`Tables`** tab. `lib/i18n.ts` owns the `Lang` (`'en' | 'nl'`) preference, persisted at `localStorage['bb:lang']` and shared through **`useSyncExternalStore`** (not `useState` + an effect — that sets state inside an effect *and* gives every component its own copy, so a switch in one open modal would not move a table in another; `getServerSnapshot` returns `'en'` so SSR and hydration agree). Copy lives in two modules: `tablesCopy.tsx` (the whole `Tables` tab) and `longEquityCopy.ts` (**the Long Equity card HEADINGS only** — not their tiles, legends or tooltips), each a `Record<Lang, …>` — a **type, not a lookup with a fall-back**, so a string added to English and forgotten in Dutch fails `tsc` instead of silently rendering a half-translated table.
- ⚠ **The switch is always on in the modal's control row, NOT scoped to the tab it translates.** It was tab-scoped first (the rule the SBC checkbox follows) and that was wrong twice: a language is a property of the reader rather than of one tab, and a control that only appears on `Tables` cannot be discovered without already being on `Tables` — reported immediately as "I do not see it". Coverage is stated in its `title` instead.
- ⚠ **Interpolation is a function per string, never a template with `{placeholders}`**, and the footnote returns a **ReactNode** — Dutch does not share English clause order, and the footnote emphasises a word mid-sentence. A shared skeleton with holes pins both languages to English grammar.
- ⚠ **`yearSuffix` (`y`/`j`) is one value** used by the column headings, the `3y` badge on the expectation row *and* the footnote that names that badge — a note pointing at a `3y` marker beside a column reading `3j` describes something not on screen.
- ⚠ **`MetricCfg.title` is NOT translated — `titleKey` is.** `LongEquityTab` renders the four growth cards with `key={cfg.title}`, so translating the config field would change the React key with the language and remount every card, refetching all of it to repaint four headings. The config keeps its English identity; only the rendered `<h4>` is looked up. `titleKey` is optional so a `MetricCfg` built elsewhere (`QuickValuationTab`) keeps its English heading.
- ⚠ **Cards read `useLang()` directly rather than taking a `lang` prop** — that is what the external store buys. Drilling it through fourteen siblings is fourteen chances to miss one, and a card left in English reads as a missing translation rather than a missing prop.
- ⚠ **The two surfaces must agree**: the `Tables` tab summarises the Long Equity cards *in the same modal*, so a metric's Dutch name has to be identical in both files (`vrije kasstroom / aandeel`, `rendement op geïnvesteerd vermogen`). Pinned by a cross-file assertion in `longEquityCopy.test.ts`; `longEquityCopy.test.ts` also asserts the **English** headings verbatim, because they were lifted out of fourteen components and a typo there silently renames a chart.
- **Deliberately NOT translated**: the dash tooltips (`Cagr.reason`, `WindowMean.reason`) — they come from `lineCagr.ts`/`windowStats.ts`, pure modules shared with `CagrTable` and the growth cards, and threading a language through them would duplicate the diagnostics or translate surfaces nobody asked for; plus benchmark labels, portfolio names and server error text. `tablesCopy.test.tsx` asserts the Dutch is not the English pasted across (explicit `SHARED` allow-list for genuine overlaps like "ROIC").

**Stores** (`frontend/lib/stores/`): lightweight reactive `createStore`. `momentum.ts` holds SSE-driven backtest + current portfolio state.
